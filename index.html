Sobre este protótipo

JTekt Smart Storage é um protótipo funcional construído em HTML, CSS e JavaScript puro, sem backend. Todos os dados são simulados e armazenados localmente no navegador. Funcionalidades como leitura de código de barras/QR e câmera são simuladas visualmente, sem integração real com hardware.
